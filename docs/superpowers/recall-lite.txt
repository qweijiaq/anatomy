## 这个数字意味着什么

29 个仓库、90 个标注点，其中 54/90 = 60% 被候选覆盖。

剩下没覆盖的点里，**没有一类是「再加一条正则就能修」的**：

- 短函数里的一处判断（`dlv` 六行、`p-all` 五行），任何基于长度、嵌套、词表的规则都看不见；
- 需要解析语义而不是匹配形状的情况，意味着换解析器（TS 编译器 API 与 Python `ast` 都已在依赖里）。

data-integrity / resilience / idiom 四类信号。其中 idiom 那条是专门为上面「短函数里的一处判断」
加的，`dlv` 与 `p-all` 因此从 0 到 3/3、3/3。

数字从 46% 到 60%，涨的 13 个点里有 6 个来自 `dlv` / `p-all` / `etag` 这三个曾经零候选的仓库。
